连接 Codex 工具

你只需要完成下面 3 件事 按 1 → 3 顺序操作即可。Tunnel、API Key 和 ChatGPT 必须使用同一个 OpenAI 账号。

打开 Tunnel 创建页面
2创建普通 API Key 并连接待创建

创建普通 API Key（不是 Admin key），并确保它和上面的 Tunnel、当前 ChatGPT 登录使用同一个 OpenAI 账号。已保存的 Key 不会在页面重新显示。

打开 API Key 创建页面
RCMAKER

默认名称为 RCMAKER Codex。修改后需要在 ChatGPT 新建对应名称的插件，再检查连接；已有任务不受日常设置保存影响。

3创建 ChatGPT Connector等待

Tunnel 和 API Key 页面在你当前使用的浏览器中新标签页打开。ChatGPT 登录和 Connector 创建使用内置 Chrome，确保插件绑定到网页模型使用的账号。创建完成后点击“检查连接器”。

  1. 先在 ChatGPT 设置中启用 Developer Mode。
  2. 新建 Connector，类型/来源选择 Tunnel，并选择刚才创建的 Tunnel。
  3. 连接器名称必须填写 RCMAKER Codex。不要把旧连接器直接改名；MCP 契约升级后需要创建新连接器身份。
  4. Authentication 选择 None。
  5. 保存 Connector 即可；不要在顶部全局权限里寻找“Allow all actions”。不同账号/Workspace 显示的权限项可能不同，RCMAKER 会用无主机副作用的命令类探针实际验证能力。
  6. 只有 RCMAKER 更新了工具名称、参数或权限标记时，才需在 ChatGPT 的连接器页面点击 Refresh 并核对工具清单。普通重启不需要；这里的“检查连接器”只验证连通性，不刷新 ChatGPT 保存的工具目录。
  7. 如果第一次创建失败而 Tunnel 已连接，可等待 5–10 秒再试一次；完成后点击“检查连接器”。

4. 在 Codex 中启用 Web 模型

先检测当前 ChatGPT 账号的可用模型，再预览并保存接入配置。保存工作后完全退出 Codex（包括后台进程）再打开，保持 RCMAKER 运行。
